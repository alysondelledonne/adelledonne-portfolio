# alysondelledonne.github.io

Personal site for Alyson DelleDonne: about, education, writing (bits & gloss), and the OpenShift homelab.

It is a single static `index.html` with no build step. GitHub Pages serves it from the `main` branch root.

## Updating
- Edit `index.html` and commit. Each section (`#about`, `#education`, `#writing`, `#homelab`) is a `<section class="page">`.
- Homelab progress: change a phase's pill from `planned` / `up next` to `done` only when that phase is finished.
